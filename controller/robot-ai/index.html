Robot AI 4WD

Robot beroda empat yang bisa diajak ngobrol, digerakkan dari layar sentuh atau Telegram, melihat lewat kamera, memutar musik, mengikuti benda di depannya, dan berjaga. Dirakit bertahap dari baterai sampai AI, dengan tes kecil di setiap langkah.

Jujur dulu

Status panduan ini

Sudah dicek

  • Ketiga kode lengkap dan 13 kode tes berhasil dikompilasi dengan Arduino ESP32 core 3.3.12 dan library terbaru.
  • Pin dipilih untuk menghindari pin boot, PSRAM, dan USB di kedua ESP32.
  • Tegangan tiap modul dicocokkan dengan lembar datanya.

Belum dicek

  • Robot lengkapnya belum dirakit dan diuji di perangkat nyata.
  • Urutan pin TB6612 dan layar berbeda antar-penjual. Panduan ini sudah dicocokkan dengan foto modulmu, tapi tetap cocokkan nama pin yang tercetak saat menyambung.
  • Suara robot memakai layanan Google TTS tidak resmi yang bisa berhenti kapan saja.
Gambaran

Tiga board, satu robot

Geser gambar ke samping untuk melihat semuanya.

Robot dibagi tiga karena satu ESP32 tidak punya cukup pin untuk semuanya. Badan (DevKit V1) mengurus hal yang harus cepat dan aman: motor, sensor, berhenti sendiri. Otak (ESP32-S3) mengurus layar, suara, dan internet. Mata (ESP32-CAM) hanya mengambil foto. Otak dan badan bicara lewat 3 kabel UART dengan perintah teks sederhana, jadi kamu bisa mengetes badan sendirian dari Serial Monitor.

Berkas

Kode

  • robot-ai-kode.zip: semua kode dalam satu file (3 kode lengkap + 13 kode tes, masing-masing di foldernya sendiri, siap dibuka Arduino IDE).
  • robot_badan.ino: untuk DevKit V1 (board: ESP32 Dev Module).
  • robot_otak.ino: untuk ESP32-S3 (board: ESP32S3 Dev Module, PSRAM OPI, Huge APP).
  • robot_mata.ino: untuk ESP32-CAM (board: AI Thinker ESP32-CAM, Huge APP).
  • Isi WiFi, token, dan API key hanya di komputermu. Jangan unggah file yang sudah terisi ke GitHub.
