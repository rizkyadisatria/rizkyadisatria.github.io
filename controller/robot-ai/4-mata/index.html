Gambaran

Kenapa kamera punya board sendiri

Modul kamera OV2640 telanjang yang kamu punya butuh tegangan 2,8 V dan 1,2 V yang tidak tersedia di papan S3. ESP32-CAM sudah membawa pengatur tegangan itu, kameranya, dan WiFi sendiri. Jadi kamera robot menjadi board ketiga yang mengirim foto lewat WiFi: otak tinggal meminta http://alamat-kamera/capture.

ESP32-CAM-MB adalah papan downloader: ESP32-CAM ditancapkan di atasnya supaya bisa di-upload lewat micro-USB. Di robot, ESP32-CAM dilepas dari MB dan diberi daya 5 V langsung.

/*
  ROBOT AI 4WD - MATA (ESP32-CAM AI-Thinker)
  -------------------------------------------
  Menyambung ke WiFi rumah lalu menyediakan foto lewat alamat web:
    http://robotcam.local/capture          foto JPEG 640x480
    http://robotcam.local/capture?res=qvga foto 320x240 (untuk layar robot)
    http://robotcam.local/stream           video MJPEG (buka di browser)
    http://robotcam.local/flash?on=1       nyalakan LED flash (on=0 mematikan)
    http://robotcam.local/status           info singkat
  Kalau "robotcam.local" tidak bisa dibuka (sering di HP Android), pakai alamat IP
  yang dicetak di Serial Monitor saat menyala.

  Board di Arduino IDE : AI Thinker ESP32-CAM
  Partition Scheme     : Huge APP (3MB No OTA/1MB SPIFFS)
  Upload lewat papan ESP32-CAM-MB (port micro-USB). Tidak perlu library tambahan.
  Kamera OV2640 dan OV3660 sama-sama didukung (dideteksi otomatis).
*/

#include "esp_camera.h"
#include <WiFi.h>
#include <WebServer.h>
#include <ESPmDNS.h>

// ================== ISI DENGAN WIFI RUMAHMU (2.4 GHz) ==================
const char* WIFI_NAMA     = "NAMA_WIFI";
const char* WIFI_PASSWORD = "PASSWORD_WIFI";
const char* NAMA_MDNS     = "robotcam";        // jadi robotcam.local
const bool  KAMERA_TERBALIK = false;           // true kalau gambar terbalik atas-bawah

Kode lengkap: unduh robot_mata.ino. Tidak perlu library tambahan.

Berhasil kalau

Serial Monitor menulis jenis sensor (untuk kameramu: OV3660) dan Tersambung. Alamat kamera: http://192.168.x.x.

Kalau tidak berhasil
  • "Kamera gagal mulai, kode 0x105" atau 0x20004: pita kamera tidak rapat. Cabut USB, buka kunci soket, masukkan ulang pita, tekan kunci.
  • "Brownout detector was triggered" lalu restart terus: daya USB kurang kuat. Pakai port USB lain di laptop atau kabel lebih pendek.
  • WiFi gagal: kamera hanya bisa WiFi 2.4 GHz, dan antena kecilnya lemah. Dekatkan ke router saat mencoba.

Tahap 3

Pindah ke daya robot dan pasang di kepala

LM2596 #2 (5,0 V)Kapasitor 1000 µFKabel 26 AWG merah dan hitam2 potongan jumper betina 3 cmHeat shrink2 cable ties

Geser gambar ke samping untuk melihat semuanya.

Dilihat dari atas, posisi barang sama persis dengan di robot (gambar tata letak Bagian 6). Nomor di gambar = nomor di tabel dan di langkah. Kabel 23 (5 V kamera) naik dari LM2596 #2 di lantai 1 lewat lubang HSV.

Kenapa begitu? Saat WiFi mengirim, ESP32-CAM bisa menarik arus sesaat yang besar. Kapasitor 1000 µF memasok lonjakan itu sehingga tegangan tidak drop dan kamera tidak restart. Untuk upload kode lagi nanti, tancapkan kembali ke MB.

Berhasil kalau

Foto bisa dibuka dari browser walau ESP32-CAM hanya mendapat daya dari baterai. Saat kepala menoleh, kamera ikut menoleh.
