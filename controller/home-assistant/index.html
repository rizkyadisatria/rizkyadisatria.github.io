Stasiun Cuaca di Home Assistant

Hasilnya: suhu, kelembapan, dan cahaya kamarmu muncul di dashboard Home Assistant, dan LED serta buzzer bisa dinyalakan dari sana atau otomatis kalau kamar panas. Rangkaian di breadboard tidak berubah. Yang berubah hanya program di ESP32.

0 / 0 langkah

Sebelum mulai

  • Home Assistant (HA) adalah aplikasi rumah pintar yang jalan di komputer. Ia mengumpulkan semua perangkat di satu dashboard dan menjalankan otomasi.
  • ESPHome adalah cara membuat firmware ESP32 dari berkas konfigurasi YAML, tanpa menulis kode Arduino. Perangkatnya muncul di HA secara otomatis.
  • Rangkaian dari panduan Stasiun Cuaca (Tahap 0–5) harus sudah terpasang dan sensornya sudah terbukti jalan.
Konsekuensi yang perlu kamu tahu

ESP32 hanya menjalankan satu firmware. Setelah di-flash dengan ESPHome, bot Telegram dari panduan sebelumnya tidak jalan lagi (kodenya tertimpa). Kamu bisa mengembalikannya kapan saja dengan upload ulang stasiun_cuaca.ino. Notifikasi Telegram bisa dibuat lagi lewat HA, itu opsional di Tahap 7.

Laptop harus menyala

HA jalan di laptopmu, jadi dashboard dan otomasi hanya aktif selama laptop hidup dan tidak sleep. Cocok untuk belajar. Untuk dipakai terus-menerus, nanti sebaiknya pindah ke Raspberry Pi atau mini PC.

Tahap 1

Pasang Docker Desktop

Docker membungkus HA dalam satu "wadah" supaya tidak mengotori Windows-mu.

  1. Buka docker.com/products/docker-desktop, unduh dan install Docker Desktop untuk Windows. Biarkan opsi WSL 2 tercentang.
  2. Restart laptop kalau diminta, lalu buka Docker Desktop dan tunggu ikon paus di pojok kiri bawah berwarna hijau (Engine running).
  3. Buka PowerShell dan ketik docker --version. Harus muncul nomor versi.
Kalau muncul pesan virtualisasi

Aktifkan Virtualization (VT-x / SVM) di BIOS laptop. Nama menu berbeda tiap merek. Cari tulisan itu di panduan laptopmu.

Tahap 2

Jalankan Home Assistant

  1. Buat folder C:\ha.
  2. Simpan berkas di bawah dengan nama docker-compose.yml di folder itu (atau unduh).
# Home Assistant di Docker Desktop (Windows). Simpan di C:\ha\docker-compose.yml
services:
  homeassistant:
    container_name: homeassistant
    image: ghcr.io/home-assistant/home-assistant:stable
    restart: unless-stopped
    ports:
      - "8123:8123"
    volumes:
      - ./config:/config
    environment:
      - TZ=Asia/Makassar
  1. Di PowerShell: cd C:\ha lalu docker compose up -d. Unduhan pertama beberapa menit.
  2. Buka http://localhost:8123 di browser. Tunggu sampai muncul layar "Welcome", lalu buat akun pemilik (nama, username, password). Simpan password itu baik-baik.
  3. Ikuti pertanyaan lokasi dan satuan. Pilih Celsius dan zona waktu Asia/Makassar.
Berhasil kalau

Kamu masuk ke halaman Overview HA. Kalau halaman tidak terbuka, buka Docker Desktop dan lihat apakah container homeassistant berstatus Running.

Tahap 3

Pasang ESPHome di Windows

  1. Install Python 3.12 atau lebih baru dari python.org. Centang Add python.exe to PATH di layar pertama installer.
  2. Buka PowerShell baru: pip install esphome
  3. Cek: esphome version harus menampilkan nomor versi.
  4. Buat folder C:\esp. Simpan dua berkas di situ: stasiun-cuaca.yaml dan secrets.yaml.contoh.
  5. Ganti nama secrets.yaml.contoh menjadi secrets.yaml, lalu isi: nama WiFi 2.4 GHz dan passwordnya, serta api_key. Buat kunci dengan perintah python -c "import base64,os;print(base64.b64encode(os.urandom(32)).decode())" dan tempel hasilnya.
Rahasia

secrets.yaml berisi password WiFi dan kunci perangkat. Jangan unggah ke GitHub atau kirim ke siapa pun. Berkas stasiun-cuaca.yaml sendiri aman dibagikan karena hanya merujuk ke secrets.

Tahap 4

Flash pertama lewat USB

Isi konfigurasinya (pin sama dengan panduan sebelumnya):

# ESPHome untuk stasiun cuaca kamar. Pin sama dengan panduan sebelumnya.
# DHT11 = D4, LDR = D34, LED = D25, buzzer aktif = D26.
esphome:
  name: stasiun-cuaca
  friendly_name: Stasiun Cuaca
  # Board-mu pernah restart terus dengan QIO/80MHz, jadi pakai DIO/40MHz seperti yang berhasil.
  platformio_options:
    board_build.flash_mode: dio
    board_build.f_flash: 40000000L

esp32:
  board: esp32dev
  framework:
    type: arduino

logger:

api:
  encryption:
    key: !secret api_key

ota:
  - platform: esphome
    password: !secret ota_password

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password
  # Kalau WiFi hilang, ESP32 membuat hotspot sendiri untuk diatur ulang
  ap:
    ssid: "Stasiun-Cuaca-Fallback"
    password: !secret ap_password

captive_portal:

sensor:
  - platform: dht
    pin: GPIO4
    model: DHT11
    temperature:
      name: "Suhu"
    humidity:
      name: "Kelembapan"
    update_interval: 10s

  # LDR + resistor 10k di D34. Nilai 0-100 persen, makin besar makin terang.
  - platform: adc
    pin: GPIO34
    name: "Cahaya"
    attenuation: 12db
    update_interval: 5s
    unit_of_measurement: "%"
    icon: mdi:brightness-6
    accuracy_decimals: 0
    filters:
      - multiply: 30.3030   # 3.3 V -> 100 (3.3 x 30.303 = 100)
      - sliding_window_moving_average:
          window_size: 6
          send_every: 1

output:
  - platform: gpio
    pin: GPIO25
    id: led_out

light:
  - platform: binary
    name: "LED Peringatan"
    output: led_out

switch:
  # Buzzer AKTIF: cukup HIGH untuk berbunyi. Mati sendiri setelah 5 detik supaya tidak lupa.
  - platform: gpio
    pin: GPIO26
    name: "Buzzer"
    id: buzzer
    restore_mode: ALWAYS_OFF
    on_turn_on:
      - delay: 5s
      - switch.turn_off: buzzer

button:
  - platform: restart
    name: "Restart"
Entitas di HAPinKomponen
Suhu, KelembapanD4DHT11
CahayaD34LDR + resistor 10 kΩ
LED PeringatanD25LED merah
BuzzerD26Buzzer aktif (mati sendiri setelah 5 detik)
  1. Tutup Arduino IDE (atau setidaknya Serial Monitor), karena ia memegang port COM5 dan akan memblokir flash.
  2. Colok ESP32 lewat USB. Di PowerShell: cd C:\esp lalu esphome run stasiun-cuaca.yaml --device COM5
  3. Kompilasi pertama mengunduh banyak alat dan bisa 5–15 menit. Itu normal. Kalau macet di "Connecting....", tahan tombol BOOT di ESP32 sampai persentase upload muncul.
  4. Setelah selesai, log berjalan dan menampilkan alamat IP ESP32 (mis. 192.168.1.23) serta nilai suhu. Catat IP itu.
Berhasil kalau

Log menampilkan Successfully connected ke WiFi dan angka suhu, kelembapan, dan cahaya muncul tiap beberapa detik.

Kalau restart terus (load:0xffffffff)

Konfigurasi ini sudah memakai flash DIO/40MHz seperti yang menyelesaikan masalah boot loop di board-mu. Kalau tetap terjadi, tambahkan esp32: flash_size: 4MB di bawah board dan flash ulang.

Flash berikutnya tidak perlu kabel: esphome run stasiun-cuaca.yaml lalu pilih opsi lewat jaringan (OTA).

Tahap 5

Tambahkan ke Home Assistant

  1. Di HA: Pengaturan → Perangkat & layanan. Kalau muncul kartu "Ditemukan: Stasiun Cuaca", klik Konfigurasi.
  2. Kalau tidak muncul (umum di Docker Windows): klik Tambah integrasi, cari ESPHome, isi Host dengan IP dari Tahap 4 dan port 6053.
  3. Saat diminta encryption key, tempel nilai api_key dari secrets.yaml.
  4. Buka perangkat Stasiun Cuaca. Harus ada 3 sensor, 1 lampu, 1 switch, dan tombol Restart.
Berhasil kalau

Suhu dan kelembapan terbaca, dan menekan switch Buzzer membuat buzzer berbunyi (mati sendiri dalam 5 detik). Lampu LED Peringatan menyalakan LED merah.

Tiup napas ke DHT11

Angka kelembapan di HA naik beberapa persen. Itu bukti jalur sensor sampai ke dashboard.

Tahap 6

Dashboard dan otomasi alarm

  1. Buka Overview dan klik ikon pensil untuk mengedit, lalu Tambah kartu. Pilih Gauge untuk Suhu (min 15, maks 45) dan Entities untuk Kelembapan, Cahaya, LED, dan Buzzer.
  2. Buat otomasi: Pengaturan → Otomasi & Pemandangan → Buat otomasi → Buat dari awal. Klik menu titik tiga di kanan atas, pilih Edit di YAML, hapus isinya, dan tempel ini:
# Tempel di HA: Pengaturan > Otomasi > Buat otomasi > menu titik tiga > Edit di YAML
alias: Alarm suhu kamar
description: Panas di atas 31 C = LED dan buzzer menyala. Turun di bawah 29 C = LED mati.
triggers:
  - trigger: numeric_state
    entity_id: sensor.stasiun_cuaca_suhu
    above: 31
    id: panas
  - trigger: numeric_state
    entity_id: sensor.stasiun_cuaca_suhu
    below: 29
    id: normal
actions:
  - choose:
      - conditions:
          - condition: trigger
            id: panas
        sequence:
          - action: light.turn_on
            target:
              entity_id: light.stasiun_cuaca_led_peringatan
          - action: switch.turn_on
            target:
              entity_id: switch.stasiun_cuaca_buzzer
          - action: persistent_notification.create
            data:
              title: Kamar panas
              message: "Suhu {{ states('sensor.stasiun_cuaca_suhu') }} °C"
      - conditions:
          - condition: trigger
            id: normal
        sequence:
          - action: light.turn_off
            target:
              entity_id: light.stasiun_cuaca_led_peringatan
mode: single
  1. Simpan. Tes: tutup DHT11 dengan tangan hangat atau dekatkan ke gelas air panas sampai suhu melewati 31 °C. LED menyala, buzzer berbunyi, dan muncul notifikasi di HA.
Dua angka, bukan satu

Menyalakan di 31 °C dan mematikan di 29 °C mencegah alarm hidup-mati berulang saat suhu naik turun di sekitar batas (disebut hysteresis).

Kalau otomasi tidak jalan

Nama entitas bisa berbeda. Buka perangkat Stasiun Cuaca di HA, klik entitasnya, ikon roda gigi, dan lihat ID Entitas. Samakan dengan isi YAML (sensor.stasiun_cuaca_suhu dan seterusnya).

Tahap 7 · opsional

Notifikasi Telegram lewat HA

Bot yang kamu buat sebelumnya bisa dipakai lagi sebagai kanal notifikasi. Di HA: Tambah integrasi → Telegram bot, pilih Polling, masukkan token dari BotFather dan chat ID-mu. Lalu di otomasi, tambahkan aksi notify.send_message ke entitas Telegram yang muncul. Perintah seperti /status tidak otomatis ada. Itu perlu otomasi tersendiri.

Kalau ada yang tidak jalan

  • esphome tidak dikenali: tutup dan buka PowerShell baru, atau Python belum ditambahkan ke PATH saat install.
  • Port COM5 sedang dipakai / access denied: tutup Arduino IDE dan Serial Monitor, cabut dan colok ulang USB.
  • Tidak terhubung WiFi: pastikan jaringan 2.4 GHz dan password benar. Setelah beberapa menit gagal, ESP32 membuat hotspot Stasiun-Cuaca-Fallback untuk mengatur ulang.
  • HA tidak bisa menemukan perangkat: tambahkan manual dengan IP, dan pastikan laptop dan ESP32 di jaringan WiFi yang sama.
  • IP berubah setelah router restart: tetapkan IP tetap (DHCP reservation) untuk ESP32 di pengaturan router.
  • Nilai Cahaya selalu 0 atau 100: cek resistor 10 kΩ LDR dan kabel ke D34, sama seperti Tahap 4 panduan sebelumnya.
  • Ingin kembali ke bot Telegram: upload ulang stasiun_cuaca.ino lewat Arduino IDE.
