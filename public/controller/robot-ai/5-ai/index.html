Batas gratis Gemini

Gemini dipakai lewat Google AI Studio tanpa kartu kredit. Batasnya dihitung per proyek dan per model (permintaan per menit dan per hari), dan Google tidak lagi mengumumkannya di dokumentasi: angka yang berlaku untukmu hanya terlihat di halaman batas AI Studio dan bisa berubah sewaktu-waktu. Jatah harian kembali penuh tengah malam waktu Pasifik, sekitar pukul 15.00-16.00 WITA.

Satu obrolan robot = satu permintaan; pertanyaan yang membuat robot memotret biasanya dua (memutuskan melihat, lalu menjelaskan fotonya). Kalau jatah Gemini habis, robot otomatis memakai Groq sebagai cadangan, asal kunci Groq diisi (Tahap 3). Di tingkat gratis, Google boleh memakai isi pertanyaan dan foto untuk memperbaiki layanannya; jangan kirim hal yang pribadi.

Tahap 1

Buat bot Telegram

HP dengan TelegramESP32-S3Library UniversalTelegramBot dan ArduinoJson
tes_telegram.inoUnduh
// TES WIFI + TELEGRAM: bot membalas setiap pesanmu. Library: UniversalTelegramBot, ArduinoJson
#include <WiFi.h>
#include <WiFiClientSecure.h>
#include <UniversalTelegramBot.h>

const char* WIFI_NAMA      = "NAMA_WIFI";
const char* WIFI_PASSWORD  = "PASSWORD_WIFI";
const char* TOKEN          = "ISI_TOKEN_DARI_BOTFATHER";
const char* CHAT_ID        = "ISI_ANGKA_ID_KAMU";

WiFiClientSecure client;
UniversalTelegramBot bot(TOKEN, client);

void setup() {
  Serial.begin(115200);
  delay(1500);   // beri waktu Serial Monitor tersambung
  Serial.println("\n=== TES TELEGRAM ===");
  WiFi.begin(WIFI_NAMA, WIFI_PASSWORD);
  Serial.print("WiFi");
  while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print("."); }
  Serial.print("\nTersambung, IP "); Serial.println(WiFi.localIP());
  client.setCACert(TELEGRAM_CERTIFICATE_ROOT);
  bool ok = bot.sendMessage(CHAT_ID, "Halo dari ESP32-S3! Kirim pesan apa saja.");
  Serial.println(ok ? "Pesan terkirim ke Telegram" : "GAGAL kirim. Cek token dan chat ID");
}

void loop() {
  int n = bot.getUpdates(bot.last_message_received + 1);
  for (int i = 0; i < n; i++) {
    Serial.println("Pesan masuk: " + bot.messages[i].text);
    bot.sendMessage(bot.messages[i].chat_id, "Kamu bilang: " + bot.messages[i].text);
  }
  delay(1000);
}
Berhasil kalau

Bot mengirim "Halo dari ESP32-S3!" dan membalas setiap pesanmu.

Setelah lulus: boleh dipatenkan atau belum?

Boleh dipatenkan Token bot dan chat ID.

Jangan dulu Jangan diunggah ke GitHub atau dikirim ke orang lain. Kalau bocor, buat bot baru.

Kalau tidak berhasil
  • "GAGAL kirim": token salah ketik (harus lengkap dengan angka dan titik dua), chat ID salah, atau belum menekan Start di bot.
  • WiFi tidak tersambung: ESP32 hanya bisa 2.4 GHz.
Tahap 2

API key Gemini (gratis)

Akun Google
tes_gemini.inoUnduh
// TES GEMINI API: ketik pertanyaan di Serial Monitor, jawaban AI muncul di bawahnya.
// Library: ArduinoJson. Butuh API key gratis dari aistudio.google.com (diawali AIza).
#include <WiFi.h>
#include <WiFiClientSecure.h>
#include <HTTPClient.h>
#include <ArduinoJson.h>

const char* WIFI_NAMA     = "NAMA_WIFI";
const char* WIFI_PASSWORD = "PASSWORD_WIFI";
const char* API_KEY       = "ISI_API_KEY_GEMINI";
const char* MODEL         = "gemini-2.5-flash-lite";   // samakan dengan GEMINI_MODEL di robot_otak

String tanya(const String& q) {
  JsonDocument doc;
  doc["system_instruction"]["parts"][0]["text"] = "Jawab dalam Bahasa Indonesia, singkat, paling banyak 2 kalimat.";
  JsonObject m = doc["contents"].to<JsonArray>().add<JsonObject>();
  m["role"] = "user"; m["parts"][0]["text"] = q;
  String body; serializeJson(doc, body);

  WiFiClientSecure c; c.setInsecure();     // terenkripsi, tapi sertifikat server tidak diperiksa
  HTTPClient http;
  http.begin(c, String("https://generativelanguage.googleapis.com/v1beta/models/") + MODEL + ":generateContent");
  http.addHeader("content-type", "application/json");
  http.addHeader("x-goog-api-key", API_KEY);
  http.setTimeout(30000);
  int code = http.POST(body);
  String resp = http.getString();
  http.end();
  if (code != 200) return "GAGAL (kode " + String(code) + "): " + resp;
  JsonDocument r; deserializeJson(r, resp);
  String teks;
  for (JsonObject p : r["candidates"][0]["content"]["parts"].as<JsonArray>())
    if (!(p["thought"] | false)) teks += p["text"] | "";
  return teks.length() ? teks : "(kosong): " + resp;
}

void setup() {
  Serial.begin(115200);
  delay(1500);   // beri waktu Serial Monitor tersambung
  Serial.println("\n=== TES GEMINI ===");
  WiFi.begin(WIFI_NAMA, WIFI_PASSWORD);
  while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print("."); }
  Serial.println("\nSiap. Ketik pertanyaan lalu Enter.");
}

void loop() {
  if (Serial.available()) {
    String q = Serial.readStringUntil('\n'); q.trim();
    if (q.length()) { Serial.println("Kamu: " + q); Serial.println("AI  : " + tanya(q)); }
  }
}

Kenapa begitu? Kode ini mengirim pertanyaan dalam format JSON ke alamat generativelanguage.googleapis.com lewat HTTPS, dengan kunci di header x-goog-api-key. Koneksinya terenkripsi, tapi demi kesederhanaan sertifikat server tidak diperiksa (setInsecure). Untuk proyek rumahan ini cukup; jangan pakai pola ini untuk data sensitif.

Berhasil kalau

Jawaban AI muncul dalam beberapa detik. Kode 400 dengan API_KEY_INVALID = kunci salah, 403 = kunci tidak diizinkan, 404 = nama model salah atau sudah tidak tersedia, 429 = jatah habis atau terlalu sering.

Setelah lulus: boleh dipatenkan atau belum?

Boleh dipatenkan API key Gemini dari AI Studio.

Jangan dulu Jangan taruh di berkas yang akan diunggah ke tempat publik.

/*

  Layar sentuh + wajah robot, speaker, mikrofon, SD card, bot Telegram,

  Badan (DevKit V1) dikendalikan lewat UART. Kamera (ESP32-CAM) diambil lewat WiFi.

  PENGATURAN BOARD di Arduino IDE (Tools):
    Board            : ESP32S3 Dev Module
    Flash Size       : 16MB (128Mb)
    PSRAM            : OPI PSRAM            <- wajib, tanpa ini audio dan foto gagal

                       Disabled kalau menulis "USB mode: UART"

    ESP32-audioI2S (schreibfaul1) -> tidak ada di Library Manager, pasang dari ZIP GitHub (lihat panduan)

  Isi bagian KONFIGURASI di bawah. Jangan bagikan file yang sudah berisi token/API key.
*/

#include <HTTPClient.h>

Berhasil kalau

Layar menampilkan wajah dengan dua mata yang berkedip, baris status di atas berisi baterai dan jarak dari badan, speaker berkata "Halo, aku Zond. Aku siap.", dan bot mengirim "Zond menyala".

Setelah lulus: boleh dipatenkan atau belum?

Boleh dipatenkan robot_otak.ino yang sudah terisi (WiFi, token, chat ID, API key, KAMERA_ALAMAT, nama robot). Kalibrasi sentuh tersimpan di S3.

Jangan dulu Berkas yang sudah berisi kunci jangan diunggah ke tempat publik. Roda tetap terangkat.

Kalau tidak berhasil
  • Error kompilasi "Audio.h: No such file": library audio belum terpasang dari ZIP.
  • Restart terus dengan pesan PSRAM: menu PSRAM belum OPI PSRAM.
  • "badan belum terhubung" di layar: cek kabel UART dan GND (Bagian 3 Tahap 6).
  • Tidak bersuara tapi tes speaker berhasil: Google TTS mungkin sedang menolak. Jawaban tetap dikirim lewat Telegram.

Kenapa begitu? AI diminta menjawab dalam format JSON: kalimat untuk diucapkan, ditambah daftar aksi seperti {"m":[150,150,800]} untuk maju. Kode otak menjalankan aksi itu satu per satu, dan badan tetap menolak gerakan yang berbahaya. Mode ikuti dan jaga hanya memakai sensor ultrasonik, jadi robot tidak bisa membedakan orang dan benda; ia mengikuti atau menjaga apa pun yang ada di depannya.

Berhasil kalau

Semua perintah langsung (diawali /) berjalan. Obrolan AI menjawab dalam beberapa detik.

Setelah lulus: boleh dipatenkan atau belum?

Boleh dipatenkan Semua kode dianggap final setelah tahap ini. Bagian 6 hanya menyetel konstanta (Tahap 8).

Jangan dulu Roda tetap terangkat sampai Bagian 6 Tahap 7. Jangan membongkar rangkaian meja sebelum semua fitur di tabel terbukti jalan, karena mencari penyebab sesudah dibongkar lebih sulit.

Kalau tidak berhasil
  • AI menjawab tapi robot tidak bergerak: lihat Serial Monitor. Kalau ada "E DITOLAK", ada halangan atau tombol STOP terkunci.
  • Foto gagal: kamera menyala? IP di KAMERA_ALAMAT benar? Tab /stream di browser sudah ditutup?
  • BICARA menghasilkan "Tidak terdengar jelas": bicara lebih dekat ke mikrofon, atau GROQ_API_KEY belum diisi.
  • Robot tidak menanggapi saat namanya disebut: lihat Serial Monitor. Baris "[dengar] tanpa nama, diabaikan" menunjukkan apa yang didengar; kalau namanya ditulis jauh berbeda, ganti NAMA_ROBOT dengan nama yang lebih jelas diucapkan. Robot juga tidak mendengar selama speaker berbunyi, termasuk saat musik atau radio diputar.
  • Robot berkata "Jatah AI gratis sedang habis": batas harian Gemini (dan Groq kalau diisi) sudah terpakai. Tunggu jatahnya kembali sekitar pukul 15.00-16.00 WITA, atau pilih model lain dengan jatah lebih besar di halaman batas AI Studio.
Penting

Keamanan dan privasi

  • Token bot, API key Gemini, dan API key Groq sama dengan password. Jangan unggah ke GitHub atau kirim ke orang lain. Kalau bocor, hapus kuncinya di AI Studio atau console Groq dan buat yang baru.
  • Robot hanya menurut ke chat ID-mu. Orang lain yang menemukan bot-mu akan dibalas "aku hanya menurut ke pemilikku".
  • Kamera dan mikrofon bisa merekam orang lain di rumah. Dengan DENGAR_NAMA aktif, setiap kalimat yang terdengar dikirim ke Groq untuk dicek apakah menyebut nama robot (paling banyak 10 kalimat per menit). Beritahu orang di rumah, matikan robot kalau tidak dipakai, atau isi DENGAR_NAMA = false supaya robot hanya mendengar setelah tombol BICARA.
  • Mode jaga bukan alarm keamanan sungguhan: sensor ultrasonik bisa terkecoh tirai yang bergerak, dan bisa melewatkan orang di samping.
